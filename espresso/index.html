How these numbers are calculated

All timestamps use the displayed local timezone. A saved shot is a cup proxy and can include an aborted brew; this is an archive count, not a physical cup counter. Heating and purge are excluded by matching recorded states to the profile’s stage names.

Brew time includes pre-infusion. Main extraction time excludes stages identified as pre-infusion. Within a shot, measured pressure and temperature are weighted by the time represented by each sample; across shots, each available shot mean has equal weight. Missing measurements are excluded, never treated as zero. The sample count appears beneath each average.

Output weight is the peak nonnegative scale reading during brewing and immediate draining, before cup removal/purge. This estimate can include scale noise. Target temperature comes from the profile and is separate from measured temperature. Pre-infusion detection uses configurable stage names/patterns; unnamed or differently named phases may need local configuration.

Daily averages span the first archived shot through the statistics date, including quiet days. Weekday averages use the number of Mondays, Tuesdays, etc. in that same period. Only history still available when collection began can be imported.
